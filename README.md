# personal site

Plain Next.js (App Router), no Tailwind, no component library. All the content
lives in the arrays at the top of `app/page.tsx` — edit those, not the JSX.

## run it

    npm install
    npm run dev

## before you ship it

- Replace the four `#` placeholders in `links` (GitHub, LinkedIn, email, resume).
- Drop the resume PDF in `public/` and point the link at `/resume.pdf`.
- Delete any project object you don't want; the page just renders fewer items.

## deploy

Push to GitHub, import the repo on Vercel, done. No config needed.
